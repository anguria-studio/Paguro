Blatta compatibility fixture

Use these controls inside Blatta. Each control exercises a public WebKit path. The fixture does not use an external network service.

Notifications and unread state

Notification controls test alert delivery. They do not change unread state. Use the title badge controls to test the service and Dock badges.

The service worker control tests a call made by the page through its registration. It does not emulate a push event that runs only inside a worker.
