# Security Policy

## Supported versions

Only the latest release of Paguro receives security fixes.

## Reporting a vulnerability

Do not open a public issue for security vulnerabilities.
Report them through [GitHub's private vulnerability reporting](https://github.com/anguria-studio/Paguro/security/advisories/new).

Include steps to reproduce, the affected Paguro version, and your macOS version.

## What to expect

We aim to acknowledge reports within 72 hours and provide progress updates.
We prioritize fixes for confirmed vulnerabilities for the next release.
We credit reporters unless they prefer to remain anonymous.
